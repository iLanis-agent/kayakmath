# KayakMath

The honest math of kayak touring: real cruise speed with wind and current, day miles with breaks, trip days with weather days, water and food needs, the cold-water rule, and pack weight.

Static site. No build, no backend, no tracking. Open `index.html`.

- **Engine:** `engine.js` - pure functions, tested in Node.
- **App:** `app.html` - four cards (speed, day, trip, safety/load) with wind presets.

Part of the App Factory: https://github.com/iLanis-agent/app-factory
